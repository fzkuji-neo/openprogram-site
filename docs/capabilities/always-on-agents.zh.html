常驻 Agent#

常驻 Agent 会在你离开时继续工作：按计划唤醒，在自己的会话里推进常驻目标；没有事做时用只读工具巡检新情况；发现值得你关注的事就通知你。

任何已保存的 Agent 都可以设为常驻。它使用该 Agent 的模型、指令、能力与记忆，配置方式和其他 Agent 一样。

开启#

  1. 在侧栏打开 Agents，选择要设置的 Agent。
  2. 打开 常驻 标签页，勾选 让此 Agent 常驻。
  3. 可选：填写 常驻目标，例如“保持文档站没有死链，有需要我审阅的修复时告诉我”。
  4. 选择唤醒频率（唤醒间隔，5 到 10080 分钟，默认 60）。
  5. 点 保存修改。

保存后一分钟内会第一次唤醒，之后按间隔唤醒。

每次唤醒做什么#

每次唤醒最多做一件事：

情况 结果
它的会话里已有任务在运行 不做事，下次再试
你设置了尚未开始的常驻目标 在会话中把它作为 目标 启动
目标进行中或已暂停 不做事；目标自己会继续，你设置的暂停保持不变
没有要推进的目标，且开启了巡检 进行巡检（见下文）
其他情况 不做事

如果你修改常驻目标时还有未结束的目标，新目标会在它结束后开始。想立即切换，可在会话中输入 /goal clear。

巡检#

没有目标要推进时，Agent 会巡检：回顾记忆和会话里未完结的事项，查找新情况。巡检只能用只读工具：读取和搜索文件、网页搜索与抓取、读取会话与记忆、查看待办和目标。巡检期间不能运行命令、编辑文件或调用 MCP 服务。

发现值得关注的事会发送报告，否则用一句话说明没有发现。在 巡检可以做什么 中选择：

  • 只报告发现（默认）：在报告里提出建议，由你决定是否开始。
  • 可自行开始目标：可以把发现转为目标，随后按会话的常规工具与权限执行。

关闭 没有目标时进行巡检，则它只为常驻目标唤醒。

它的会话#

每个常驻 Agent 有一个固定的会话，名为“Agent 名称 · Always-on”。目标工作、巡检和报告都在这里进行，它做过的事都能看到。你可以像普通聊天一样在这里和它对话。它的权限模式和规则就是这个会话的设置；需要审批时会在会话里等待并通知你。

删除这个会话后，下次唤醒会新建一个。

报告与通知#

报告包含标题、简短正文和可选链接。在桌面 App 中，App 窗口不在前台时每条报告都会弹出系统通知，点击即打开该 Agent 的会话。常驻 标签页会列出最近的报告。

把报告发到渠道#

报告也可以通过 聊天渠道（Telegram、Slack、Discord 或微信）发给你。在 同时把报告发到 中勾选要接收报告的会话，每条报告会作为一条消息发过去。最多可选 10 个。

列表包括此 Agent 已有的渠道会话，以及通过 peer 绑定（openprogram channels bindings add <agent> --channel telegram --account <id> --peer <id>）绑定到它的人或群。绑定到整个渠道或账号的 Agent，只会列出和它聊过的人。

报告在 App 中保存后，会向每个选中的会话各发送一次。常驻标签页会在每条报告下显示是否已发到各个会话；发送失败（例如账号已退出登录）也会显示在那里，报告本身不会丢失。

状态与立即唤醒#

常驻标签页的 状态 区域显示：

  • 会话当前在做什么（正在工作、当前目标，或暂无目标）；
  • 上次唤醒的时间和结果；
  • 下次唤醒的时间。

打开 进入该会话；立即唤醒 马上执行一次唤醒。状态和立即唤醒使用已保存的设置，修改后请先保存。

从反馈中学习#

Agent 通过记忆逐步改进。在 Agent 的 长期记忆 标签页选择 读写：会话里的纠正和偏好会写入它的记忆，并在之后的回合中使用。记忆不是读写模式时，常驻标签页会提示。

限制#

  • 工作在本机进行，使用会话的工作目录与沙箱；worker 运行时 Agent 才会唤醒。
  • 没有免打扰时段，全天按间隔唤醒。
  • 复制出来的 Agent 默认关闭常驻。

工程设计 说明了唤醒、巡检与报告的实现方式。
